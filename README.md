# stthomastrowbridge.org

Local copy and redesign workspace for https://www.stthomastrowbridge.org/ (St Thomas' Church, Trowbridge).

Charity: The Parochial Church Council of the Parish of St Thomas the Apostle, Trowbridge.

## Layout

- `crawl/pages/`: rendered HTML, visible text and link lists for every page crawled on 2026-10-19.
- `crawl/screenshots/`: full-page desktop screenshots.
- `crawl/assets/`: images and public documents linked from the site.
- `crawl/INDEX.md`: page list.
- `research/source/`: church secretary's inputs (observations, requirements, Andrew Palmer proposal, 2017 survey).
- `redesign/`: content and structure plan (scope: content design only, no build).

## Notes

- Members-only area is out of scope (no longer on the site).
- Kingfisher page (`/our-churches/kingfisher/`) is to be removed in the redesign.
- Site runs on ChurchEdit. Calendar, room hire and giving pages are the ChurchSuite touchpoints.
- Repo is private: contains named individuals from church documents.
